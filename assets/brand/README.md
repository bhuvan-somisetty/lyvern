# Lyvern brand assets

- `lyvern-bot-logo-v4-mascot-*.png`: the robot-lynx mascot used as the GitHub App logo (also `docs/assets/lyvern-bot-logo.png`).
- `lyvern-bot-logo-v2-flat-*`, `lyvern-bot-logo-v3-L-check-*`: alternative designs that were not chosen.
- `lyvern-logo-original-1254.png`: the first logo supplied by the owner.
- Generator scripts for v2, v3 and v4 are in `scripts/brand/` (Python with Pillow; run them from a folder where the PNGs may be written).
